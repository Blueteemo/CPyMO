# CPyMO for NDS 1.3.0 图标效果实机测试

这是单独提供的通用 NDS/DSi 测试 ROM，内部版本仍为 1.3.0，未正式发布。请与此前功能测试通过的无框版本分开放置。

采用的方案：轻度提清、完整构图、暖灰棕 1 像素细边框；菜单图标 32×32，默认列表占位符直接生成 24×24，加载页使用独立 64×64 图。游戏自带图标、主题、时钟、音量、游戏逻辑、缓存与存档格式保持原样。

实机请观察：

1. 系统/烧录卡菜单的图标是否清楚、边框是否自然。各菜单可能缓存历史图标，请先确认启动的是本测试文件，不要求清除系统缓存。
2. 进入游戏列表时的加载图标是否比上一版清楚，边框是否协调。
3. 没有自带图标的游戏在列表中的默认占位符，以及关于页面上的图标。
4. 能正常进入列表、启动和退出游戏，既有缓存及存档可继续使用。

`SOURCE-SHA.txt` 指明真实构建提交，`SHA256SUMS.txt` 校验测试 ROM。`ROM-VERIFICATION.json` 与 `ICON-VERIFICATION.json` 分别核对通用 ROM/版本/背景，以及真实图标资源。请反馈显示效果，正式发布继续等待本轮实机确认。
