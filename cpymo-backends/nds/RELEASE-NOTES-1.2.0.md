CPyMO for NDS 是面向 **Nintendo DS / DS Lite / Nintendo DSi** 的 PyMO 游戏引擎。一个 `.nds` 程序可以从列表选择多个游戏，支持转换 **S60v3 / S60v5 / Android PyMO 游戏数据**。

**1.2.0 新增 DSi 原生模式支持、增强双屏、游戏视频转换与播放，并大幅完善游戏资料库及触控交互。** 本版已在 **Wood R4 的 DS/NTR 模式**和 **DSpico 的 DSi/TWL 模式**进行用户实机验收；不同游戏和烧录卡仍可能存在个别兼容性差异。

**安装套件不附具体游戏。** Windows 套件包含转换所需运行组件；Apple Silicon Mac ARM64 套件需通过本机验收后才会作为正式下载提供。二者均设计为无须普通玩家另装 Python 或 FFmpeg。S60v3 / S60v5 / Android 指输入游戏的数据平台，而非转换助手运行的电脑系统。Intel Mac、Linux 可按要求运行源码工具。转换助手默认简体中文，可切换 English。

## 第一次使用

1. **Windows：** 完整解压 Windows 套件，双击“启动转换器.bat”，也可运行“Converter/Converter.exe”。**Apple Silicon Mac：** 如正式发行时提供 ARM64 套件，完整解压并从 Finder 打开 `CPyMO-NDS-Converter.app`；首次启动若出现 macOS 安全提示，应遵循系统对该应用的正式安全审查流程，不要关闭 Gatekeeper 或系统完整性保护。
2. 在电脑转换助手中选择自己的 PyMO 游戏 ZIP/APK 或包含 `gameconfig.txt` 的游戏文件夹。同包有多个平台时，一般优先选择 S60v3；选择新的输出位置，开始转换。助手可切换简体中文／English；游戏视频默认转换为 NVL1，也可选压缩音轨的 NVA1 或主动跳过视频。
3. 转换完成后阅读警告与输出目录的“安装必读”（英文界面还会生成 `INSTALL-READ-ME.txt`），将**转换结果**中的 `cpymo-nds.nds` 和 `pymo` 文件夹复制到 TF 根目录。
4. 安全弹出 TF，装回烧录卡，在 DS/DSi 上启动 `cpymo-nds.nds`，从游戏库选择游戏。

TF 卡上的游戏目录应为：

```text
TF 根目录/
├─ cpymo-nds.nds
└─ pymo/
   └─ games/
      └─ 游戏目录/
         ├─ gameconfig.txt
         ├─ script/
         ├─ nds-cache/
         └─ save/
```

保留现有烧录卡内核，无需格式化卡片。安装同名游戏前先备份自己的 `save/`，**不要用新转换结果的空存档目录覆盖旧存档**。转换器留在电脑，不必复制到 TF 卡；安装套件自带的空 `pymo/games/` 不是可直接启动的游戏。

## 功能与操作

提供带图标、标题、简介的多游戏资料库，支持列表滚动及触控；DSi 模式下可发现可访问的机身 SD 卡与烧录卡游戏。保留简体中文、繁體中文、English、日本語四语界面、时钟和辅助屏信息、原生点阵字体、存读档与文字设置。增强双屏将场景与对白分置上下屏，显示模式按游戏保存，并内置星夜背景。

| 按键／操作 | 作用 |
|---|---|
| A／DOWN／轻触 | 剧情继续；菜单／选择界面按其显示方式操作 |
| X | 游戏中打开引擎菜单；游戏库中选择界面语言 |
| B | 返回、取消；剧情中按住隐藏文字；视频播放中可提前跳过 |
| Y | 开关辅助屏及其背光 |
| L | 循环切换 **上屏游戏 → 下屏游戏 → 增强双屏** |
| R | 按游戏的快进设置跳读 |
| START | 快速保存到**标准存档 1**，会覆盖该存档 |
| SELECT | 快速读取标准存档 1；游戏库中刷新列表 |
| 合盖／开盖 | 暂停并静音／恢复 |

增强双屏在进入真实剧情前保留游戏原有标题菜单布局；播放视频时上屏显示影片，下屏暂时隐藏上一句对白，播放结束后恢复正常阅读画面。打开退出到游戏库／重启确认框时保留原来的确定、取消交互。隐藏的辅助屏位于触控屏时，首次触控只负责唤醒。

## 本版更新与升级

**相较于 1.1.0，1.2.0 的主要变化：**

- **新增 DSi 原生模式（TWL）支持。** 在兼容的 DSi 启动环境中识别 16 MiB 内存模式；资源缓存上限按实际内存条件动态调整，符合条件时可使用最多 12 项、2 MiB 的立绘／背景复用缓存，减少重复资源读取。传统 DS 的 4 MiB 运行策略保持独立，避免额外内存负担。
- **新增增强双屏与三态切换。** 按 L 在上屏游戏、下屏游戏、增强双屏之间循环；增强模式将场景、对白和选项分屏显示，支持触控并按游戏记住所选模式。游戏原有标题界面不被强制拆分；星夜背景直接内置程序。
- **新增游戏视频转换与播放。** 1.1 的转换助手会省略视频；1.2 **默认使用 NVL1** 转换常见视频，也可选压缩音轨的 **NVA1**，或主动跳过视频。支持有声／无声视频、播放完毕继续剧情和按 B 跳过；增强双屏播放期间会暂时隐藏旧对白。
- **多游戏资料库进一步升级。** 超过四款游戏时显示滚动条，可用方向键连续移动、触控滚动条与选择游戏；DSi 模式下还可扫描当前设备以外**实际可访问**的另一存储设备，游戏资源与存档保留在各自卡上（能否访问取决于启动方式）。
- **游戏内操作与细节完善。** 菜单新增「退出到游戏库」及确认操作，优化三种屏幕布局的菜单／选项触控、首次存档目录创建、存读档反馈、设置值对齐，以及加载过场和提示文字的多语言显示。
- **程序信息与兼容性维护。** 更新 NDS Banner 中的版本／移植署名，补全内置字库、改进显示模式偏好保存，同时继续读取既有的游戏数据及 1.1 缓存。新增功能不要求旧玩家全面重新转换游戏。

**从 1.1 升级：** 若已有可运行的 1.1 转换数据，只需更新 `cpymo-nds.nds`，不要覆盖游戏目录和存档。希望在旧游戏中使用视频时，需要用 1.2 转换助手从原游戏数据重新生成包含相应视频资源的缓存；建议转换至**新目录**后再按需迁移存档。1.2 新功能和对应缓存不保证可由旧版引擎运行。

1.1 中所说的“无损压缩”仍然针对转换后生成的 NDS 缓存：图像会先调整至目标分辨率和 RGB555，音频会先按 NDS 需求转换采样格式；缓存压缩不再额外降低这些已生成数据的质量。原始游戏包、剧本、汉化与署名不修改。

## 兼容性与已知限制

- **视频默认转换为 NVL1。** 用户仍可选 NVA1 或主动跳过视频。NVL1/NVA1 不意味着所有游戏、任意片长、任意烧录卡均能流畅播放；不支持的视频或不符合要求的输入会在转换审计中给出结果。
- 脚本须为 UTF-8 明文 PyMO 脚本；加密或打包脚本暂不支持。素材兼容情况请查看转换报告。
- 缺失原音频可能静音；遇到字库缺字时默认显示 □，不中断转换，并在报告中列明，原始脚本不变。
- 不同烧录卡、游戏片源、音视频码率及存储卡速度可能影响运行表现；转换成功不等于全部剧情路线与所有硬件经过认证。
