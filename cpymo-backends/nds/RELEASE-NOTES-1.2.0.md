CPyMO for NDS 是面向 **Nintendo DS / DS Lite / Nintendo DSi** 的 PyMO 游戏引擎。一个 `.nds` 程序可以从列表选择多个游戏，支持转换 **S60v3 / S60v5 / 安卓 PyMO 游戏数据**。普通 DS 烧录卡与 DSi 运行环境使用**同一个 ROM**，根据实际运行模式自动适配，不需要分别下载 NTR/TWL 版本，也不依赖 DSi 软破才能在 R4 上运行。

**1.2.0 的主要更新是增强双屏、三态显示切换、可选游戏视频转换与播放，以及更完善的游戏库交互。** 本版已在 **Wood R4 的 DS/NTR 模式**和 **DSpico 的 DSi/TWL 模式**进行用户实机验收；不同游戏和烧录卡仍可能存在个别兼容性差异。

## 第一次使用

1. 在电脑上完整解压 Windows 安装套件，双击“启动转换器.bat”，也可运行“转换器/Converter.exe”。
2. 选择自己的 PyMO 游戏 ZIP/APK 或包含 `gameconfig.txt` 的游戏文件夹。同包有多个平台时，一般优先选择 S60v3；选择新的输出位置，开始转换。如需保留游戏内视频，在“游戏视频”选项中选择支持的转换模式。
3. 转换完成后阅读警告与“安装必读”，将**转换结果**中的 `cpymo-nds.nds` 和 `pymo` 文件夹复制到 TF 根目录。
4. 安全弹出 TF，装回烧录卡，在 DS/DSi 上启动 `cpymo-nds.nds`，从游戏库选择游戏。

TF 卡上的游戏目录应为：

```text
TF 根目录/
├─ cpymo-nds.nds
└─ pymo/
   └─ games/
      └─ 游戏目录/
         ├─ gameconfig.txt
         ├─ script/
         ├─ nds-cache/
         └─ save/
```

保留现有烧录卡内核，无需格式化卡片。安装同名游戏前先备份自己的 `save/`，**不要用新转换结果的空存档目录覆盖旧存档**。转换器留在电脑，不必复制到 TF 卡；安装套件自带的空 `pymo/games/` 不是可直接启动的游戏。

## 功能与操作

提供带图标、标题、简介的多游戏资料库、简繁中英日四语界面、可选时钟和辅助屏信息、原生点阵字体、存读档、文字显示设置，以及按游戏保存的显示模式。增强双屏将场景与对白分置上下屏，并为下屏提供 ROM 内置星夜背景。

| 按键／操作 | 作用 |
|---|---|
| A／DOWN／轻触 | 剧情继续；菜单／选择界面按其显示方式操作 |
| X | 游戏中打开引擎菜单；游戏库中选择界面语言 |
| B | 返回、取消；剧情中按住隐藏文字；视频播放中可提前跳过 |
| Y | 开关辅助屏及其背光 |
| L | 循环切换 **上屏游戏 → 下屏游戏 → 增强双屏** |
| R | 按游戏的快进设置跳读 |
| START | 快速保存到**标准存档 1**，会覆盖该存档 |
| SELECT | 快速读取标准存档 1；游戏库中刷新列表 |
| 合盖／开盖 | 暂停并静音／恢复 |

增强双屏在进入真实剧情前保留游戏原有标题菜单布局；播放视频时上屏显示影片，下屏暂时隐藏上一句对白，播放结束后恢复正常阅读画面。打开退出到游戏库／重启确认框时保留原来的确定、取消交互。隐藏的辅助屏位于触控屏时，首次触控只负责唤醒。

## 本版更新与升级

**相较于 1.1.0，1.2.0 的主要变化：**

- **新增三种显示模式。** 单按 L 可在经典上屏、经典下屏和增强双屏之间轮换；增强双屏把场景与对白、选项分离，支持下屏触控。游戏标题界面仍保持原布局，显示模式按游戏保存。
- **新增可选游戏视频转换与播放。** 转换助手可将常见视频输入经 FFmpeg 转为适用于 NDS 的 **NVL1** 或 **NVA1** 格式；默认仍可选择不转换视频，保留原有兼容流程。自然播放结束和按 B 跳过后回到游戏，增强双屏视频播放期间不会残留旧对白。部分片源及硬件组合可能受性能、格式限制。
- **游戏库与交互完善。** 支持从游戏菜单直接确认退出到游戏库；改进多游戏列表滚动与触控操作，优化界面提示位置、加载游戏列表过场的语言一致性及存读档反馈。
- **显示和兼容性细化。** 下屏星夜背景直接封装到 `.nds`；单个发行 ROM 兼顾普通 DS/NTR 与 DSi/TWL 运行模式，无须单独复制背景资源，也无需准备两份不同的程序。
- **沿用 1.1 的资源优化。** 保留现有音频、图片缓存压缩策略及游戏脚本兼容性；新版本并不要求现有玩家为了上述界面改进重新转换无视频的旧游戏。

**从 1.1 升级：** 若已有可运行的 1.1 转换数据，只需更新 `cpymo-nds.nds`，不要覆盖游戏目录和存档。希望在旧游戏中使用视频时，需要用 1.2 转换助手从原游戏数据重新生成包含相应视频资源的缓存；建议转换至**新目录**后再按需迁移存档。1.2 新功能和对应缓存不保证可由旧版引擎运行。

1.1 中所说的“无损压缩”仍然针对转换后生成的 NDS 缓存：图像会先调整至目标分辨率和 RGB555，音频会先按 NDS 需求转换采样格式；缓存压缩不再额外降低这些已生成数据的质量。原始游戏包、剧本、汉化与署名不修改。

## 兼容性与已知限制

- **视频支持需在转换时主动选择。** NVL1/NVA1 并不意味着所有游戏、任意片长、任意烧录卡均有完整流畅性保证；不支持的视频或不符合要求的输入会在转换审计中给出结果。
- 脚本须为 UTF-8 明文 PyMO 脚本；加密或打包脚本暂不支持。素材兼容情况请查看转换报告。
- 缺失原音频可能静音；缺字按转换策略报错或显示方框，转换报告保留警告。
- 不同烧录卡、游戏片源、音视频码率及存储卡速度可能影响运行表现；转换成功不等于全部剧情路线与所有硬件经过认证。
